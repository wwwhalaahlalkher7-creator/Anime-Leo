# Anime Leo V1.25.2

- Added TMDB attribution notice and official TMDB logo in the About screen.
- Kept TMDB metadata usage separate from video playback; TMDB is not treated as a video source.
- Added MangaDex Arabic chapter browsing and an in-app reader using MangaDex's API and MangaDex-hosted page URLs.
- Added safe-content filtering for the MangaDex Arabic chapter feed.
- Manga pages are not stored or proxied by the Anime Leo backend.
- Added clear source/rights wording for TMDB and MangaDex.
- Kept the anime video layer disabled until an actually licensed/authorized video provider is configured.
